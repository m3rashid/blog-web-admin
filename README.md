## 📖 Overview

A blog platform with a built-in CMS and admin panel. Node.js/TypeScript backend with MongoDB storage.

## ✨ Features

- ✍️ Blog publishing & management
- 🧩 In-built CMS for content editing
- 🛡 Admin panel

## 🛠 Tech stack

`Node.js` · `TypeScript` · `MongoDB` · `Docker`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/blog-web-admin.git
cd blog-web-admin
yarn install
yarn dev
```
